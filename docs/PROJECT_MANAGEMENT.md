# Manage projects

Open http://127.0.0.1:8000/projects, or choose **Projects** in the dashboard navigation. From the extension, open History or Settings first, then choose Projects in the browser.

- **New project**: enter a name and included folder scope, such as `src`. This creates a CodeProof record, not a filesystem folder. The current active session remains selected.
- **Delete project**: review the project name and confirm. This permanently deletes that project's sessions, questions, answers, and learning history. Your code folder stays intact.
- Canceling deletion keeps the record. Failed deletion requests show a retry message.
